# Template 1 — Landing Page institucional

Base institucional para escritórios e profissionais que precisam apresentar serviços, perfil, perguntas frequentes, contato e localização.

## Fonte de dados

Edite `landing.data.json`. Nome, OAB, área, WhatsApp, localização, hero e serviços são consumidos diretamente pelo site. Não replique esses dados em componentes.

## Executar

```bash
npm install
npm run dev
```

Antes de publicar:

```bash
npm run lint
npm run build
```

Este template contém somente a rota pública da Landing Page. Login, conta, catálogo e painel administrativo não fazem parte da base.
